# Void Play — бэкенд (бот + API)

Один процесс: бот на aiogram 3 и API для сайта на порту 8080. Хостится на bothost (`voidplay.bothost.tech`).

## Как запустить на bothost

1. Залей содержимое этой папки в репозиторий (например `voidplay-backend`) и подключи его в bothost.
2. Файл запуска — `main.py`, зависимости — `requirements.txt`, порт — `8080`.
3. Заполни переменные окружения (в панели bothost или файлом `.env` — образец в `.env.example`):

| Переменная | Что вписать |
|---|---|
| `BOT_TOKEN` | токен бота от @BotFather |
| `WEBAPP_URL` | адрес сайта на GitHub Pages, например `https://ник.github.io/voidplay-webapp/` |
| `ALLOWED_ORIGINS` | `https://ник.github.io` (откуда сайт ходит в API) |
| `ADMIN_IDS` | твой Telegram id (узнать у @userinfobot) |
| `CHANNEL`, `CHANNEL_URL` | канал для задания «подпишись». **Бот должен быть админом канала** |
| `SUPPORT_URL` | ссылка на чат поддержки |

4. Запусти. В логах должно быть `API слушает 0.0.0.0:8080` и `Бот @... запущен`.
5. Проверка: открой `https://voidplay.bothost.tech/api/health` — должно ответить `{"ok": true, ...}`.

Локально: `pip install -r requirements.txt`, `cp .env.example .env`, заполнить, `python main.py`.

## Что умеет

- `/start` — приветствие и кнопка «🎮 Играть»; кнопка меню тоже ставится сама. Реферальные ссылки `t.me/бот?start=ref_ID`.
- **Пополнение**: 1 ⭐ в игре = 1 Telegram Star. Счёт на N Stars → после оплаты бот зачисляет N ⭐ на баланс.
- **Вывод** — заявка: звёзды списываются, админам приходит сообщение.
- Апгрейдер, ежедневный бонус, промокоды, задания, проверка подписки, рефералы с уровнями, лидеры сезона (месяц), LIVE-лента выигрышей, аватарки игроков.
- База — файл `voidplay.db` (SQLite) рядом с `main.py`. Не удаляй его при перезаливке.

## Админ-команды

| Команда | Что делает |
|---|---|
| `/stats` | статистика |
| `/addstars <id> <кол-во>` | начислить звёзды (с минусом — списать) |
| `/givegift <id> <gift_id>` | выдать NFT в инвентарь |
| `/promo <КОД> <награда> <активаций>` | создать промокод |

## Где что менять

- Цены и названия NFT, задания, уровни рефералки — `backend/catalog.py`
- Награды, комиссия апгрейдера, минимальный вывод — переменные в `.env`
- Логика — `backend/game.py`, API — `backend/web.py`, бот — `backend/bot.py`
