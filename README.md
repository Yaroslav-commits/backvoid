# Void Play — бот и API

Telegram-бот (aiogram 3) и HTTP API для сайта в одном процессе.

| Файл | Что внутри |
|---|---|
| `main.py` | бот, API `/api/*`, запуск |
| `game.py` | база SQLite и вся игровая логика (апгрейдер, мины, бонусы, рефералка) |
| `pvp.py` | PvP: рулетка и «Огонь и лёд» |
| `services.py` | фоновые задачи: цены подарков из Telegram, курс и переводы TON, таймер PvP |
| `config.py` | настройки, каталог NFT, задания, уровни |

## Запуск на bothost.ru

1. Залей репозиторий, команда запуска: `python main.py`.
2. В переменных окружения задай `BOT_TOKEN`, `WEBAPP_URL` и `PORT` (см. `.env.example`).
3. Включи в панели домен для бота — по нему сайт ходит в API.
4. Открой в браузере `https://<домен-бота>/api/health` — должно показать `"ok": true`.
5. Впиши этот домен в `config.js` сайта (`API_BASE`).

### Вариант без CORS
Если положить сайт рядом с ботом и задать `WEBAPP_DIR=путь/к/сайту`, бот сам раздаёт
сайт со своего домена. Тогда `WEBAPP_URL=https://<домен-бота>/`, а `API_BASE` в `config.js` — пустая строка.

## Первый заработок без вложений
Новый игрок сразу получает `WELCOME_BONUS` звёзд (по умолчанию 10, `0` — выключить),
дальше — подписка, ежедневный бонус, задание «5 ставок» и рефералы. Пополнять не нужно.

## PvP
Две игры, где игроки играют друг против друга, а проект берёт комиссию `PVP_FEE` с выигрыша:

- **Рулетка** — общий банк, шанс = твоя ставка / банк, победитель забирает всё.
- **Огонь и лёд** — две стороны, шанс стороны = её банк / общий банк; победители делят банк проигравших.

Раунд стартует, когда есть с кем играть (2 игрока / обе стороны), до этого ставку можно забрать.
Результат проверяемый: в начале раунда виден `hash = sha256(seed)`, после — сам `seed`; число раунда = `sha256(seed:id)`.

## Открыть / закрыть игру
`/games` — кнопки, `/close mines`, `/open mines`, `/close all`. Игры: `upgrade`, `mines`, `roulette`, `fireice`.
Закрытая игра на сайте помечается «Закрыто», ставки в неё не принимаются.

## Цены подарков
При `GIFTS_SOURCE=telegram` бот раз в `GIFTS_SYNC_MINUTES` минут берёт у Telegram официальный список подарков
и их цены в звёздах — каталог и цены обновляются сами, вручную ничего выставлять не нужно.
Картинки подарков бот отдаёт сам (`/api/gift/<id>`). `/syncgifts` — обновить сейчас.
Пока Telegram не ответил, используется запасной список `GIFTS` из `config.py`.

## Пополнение в TON
1. Укажи `TON_WALLET` — адрес своего кошелька.
2. Игрок выбирает TON, получает сумму и комментарий вида `VP123`, переводит.
3. Бот каждые 15 секунд смотрит входящие переводы (toncenter.com) и по комментарию зачисляет звёзды.

Курс TON берётся с биржи автоматически; `STAR_USD` — цена звезды, `TON_FEE` — твоя комиссия.

## API

| Метод | Путь | Что делает |
|---|---|---|
| GET | `/api/health` | проверка связи |
| POST | `/api/auth` | вход по initData, всё состояние игрока |
| GET | `/api/feed`, `/api/leaders` | лента выигрышей, лидеры сезона |
| POST | `/api/daily`, `/api/promo`, `/api/subscribe/check`, `/api/tasks/claim` | бонусы |
| POST | `/api/upgrade` | апгрейдер |
| POST | `/api/mines/start`, `/api/mines/open`, `/api/mines/cashout` | мины |
| GET/POST | `/api/pvp`, `/api/pvp/bet`, `/api/pvp/cancel` | PvP: состояние раунда, ставка, забрать ставку |
| POST | `/api/invoice`, `/api/withdraw` | пополнение Stars, вывод |
| POST | `/api/ton/invoice`, `/api/ton/check` | пополнение в TON |
| GET | `/api/gift/{id}` | картинка подарка из Telegram |

Все запросы подписаны `X-Init-Data` (проверка подписи Telegram).
